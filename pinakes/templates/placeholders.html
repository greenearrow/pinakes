Placeholders

An app's default bytes held under many names (the same minimal sidecar beside every photo, the objects a game writes with nothing stored in them) aren't copies of one another. Marked, or matched by a site rule, a placeholder gets no copy link, and only-here, safe to delete, duplicates and If a disk failed count only its own backups as its copies. You mark a content only where every file holding it is yours or co-owned.
